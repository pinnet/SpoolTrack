## How to Contribute

We welcome contributions from everyone! Here's how you can help:

### Code Contributions
- **Web Service**: Improve API endpoints, add features, optimize database queries
- **Klipper Plugin**: Enhance tracking accuracy, add new features
- **Firmware**: ESP32 improvements, new display modes, better NFC handling
- **Documentation**: Fix typos, improve guides, add translations

### Hardware Contributions
- **PCB Design**: Complete the custom PCB, create alternatives
- **3D Models**: Design new enclosures, create mounting solutions
- **Testing**: Build hardware, report issues, suggest improvements

### Documentation
- **Guides**: Assembly instructions, troubleshooting tips
- **Translations**: Help make SpoolTrack accessible globally
- **Video Tutorials**: Create installation and usage videos

### Community Support
- Answer questions in discussions
- Help troubleshoot issues
- Share your builds and modifications
- Spread the word about SpoolTrack

## Contribution Process

1. **Fork the Repository**
2. **Create a Feature Branch** (`git checkout -b feature/amazing-feature`)
3. **Make Your Changes**
4. **Test Thoroughly**
5. **Commit Your Changes** (`git commit -m 'Add amazing feature'`)
6. **Push to Branch** (`git push origin feature/amazing-feature`)
7. **Open a Pull Request**

See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed guidelines.
